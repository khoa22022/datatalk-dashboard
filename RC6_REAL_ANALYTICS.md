# DataTalk V2.1 RC6 - Real Analytics Dashboard

- Real `/dashboard` now follows the visual structure of the trial UX Intelligence dashboard.
- No mock numbers are used on authenticated project dashboards.
- Available real metrics: active users, sessions/page views internally, active time, friction, device mix, page attention, task data, daily trend.
- Unsupported/not-yet-defined metrics such as UX Health Score display `--`.
- Previous-period deltas display `--` when no previous-period data exists.
- Empty charts/cards remain visible with `--` and an explanatory empty state.
- EN/VI content is supported in the real dashboard.
