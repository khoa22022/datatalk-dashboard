# DataTalk Frontend V2.1.0-rc.2

Final frontend package for the `release/v2-gd01` branch.

## Included fixes
- Restores the V2 account/auth shell (`AuthProvider`, `ProjectProvider`, `AuthGate`) and browser PKCE callback flow.
- Keeps protected API bearer-token behavior and workspace/project isolation UI.
- Fixes the Vercel TypeScript nullability failure in `app/projects/[id]/connect/page.tsx` by narrowing `project` before creating a stable `projectId` used by async handlers.
- Adds the V2.1 tracking onboarding and `tracking/status` + `tracking/setup` flow.
- Moves account/help/logout controls to the top-right account menu.
- Adds password show/hide controls to login/register/reset forms.
- Keeps project/workspace selectors and Super Admin navigation from GD01.
