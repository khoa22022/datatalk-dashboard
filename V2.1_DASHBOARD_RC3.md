# DataTalk Backend V2.1 RC3 - Dashboard Aggregation

Adds authenticated `GET /api/projects/:projectId/dashboard?days=7|30`.

The endpoint aggregates observed event data for the authenticated project:
- overview metrics and friction count
- daily trend
- page attention
- device mix inferred from tracked session metadata
- task efficiency when task events exist
- observed UX signals
- previous-period comparison only when previous data exists

`uxHealthScore` deliberately returns `null`; the frontend renders `--` until a defined scoring engine is implemented.
