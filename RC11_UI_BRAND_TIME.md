# DataTalk V2.2 RC11 — UI, Brand & Time

- Session timestamps use a defensive API timestamp parser: zone-less database timestamps are treated as UTC, then formatted in `Asia/Ho_Chi_Minh`.
- All analytics filter surfaces open with `Hôm nay / Today` selected from the first render.
- The active quick-filter state uses an outline/secondary treatment so it does not compete with primary actions.
- Application branding uses the supplied DataTalk logo and canonical name `DataTalk`.
- Browser metadata/favicon uses the new logo.
